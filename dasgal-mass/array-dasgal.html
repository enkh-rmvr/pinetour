ХИЧЭЭЛ 14 · МАССИВ

Массив — 10 дасгал

[ ] · [0] · .length · length - 1 · arr[i] = … · for + массив · console.log

ЭХЛЭХ

  1. Шинэ хавтас нээгээд index.html, script.js гэсэн хоёр файл үүсгэ.
  2. index.html-д доорх кодыг хуул. <script> нь body-гийн хамгийн доор байна.
  3. Дасгал бүрийг script.js-д бич. Дараагийн дасгал руу шилжихдээ өмнөхөө /* */-аар comment болго.
  4. Console-оо нээ: Cmd + Option + J. Алдаа гарвал улаан мөрийг унш.
<!doctype html>
<html lang="mn">
  <head>
    <meta charset="UTF-8" />
    <title>JS дасгал</title>
  </head>
  <body>
    <h1>JS дасгал</h1>

    <script src="script.js"></script>
  </body>
</html>
ДАСГАЛ 1

Долоо хоногийн өдрүүд 📅

Эхний өдөр, 3 дахь өдөр, сүүлийн өдөр, нийт хэдэн өдөр байгааг хэвлэ. Сүүлийн өдрийг олохдоо 6 гэж бүү бич — length ашигла.

ЭХЛЭХ КОД — хуулж ав

const days = ["Даваа", "Мягмар", "Лхагва", "Пүрэв", "Баасан", "Бямба", "Ням"];

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› Эхний өдөр: Даваа› 3 дахь өдөр: Лхагва› Сүүлийн өдөр: Ням› Нийт 7 өдөр

💡 1 дэх нь [0], 3 дахь нь [2]. Сүүлийнх нь days.length - 1 дугаартай.

Хэрэглэх: [0] · .length · length - 1 · `${ }`

ДАСГАЛ 2

Playlist 🎵

current нь одоо тоглож буй дууны ИНДЕКС. Өмнөх, одоогийн, дараагийн дууг хэвлэ. current-ийг 3 болговол өөр дуунууд гарах ёстой.

ЭХЛЭХ КОД — хуулж ав

const songs = ["Өглөө", "Хавар", "Тал нутаг", "Бороо", "Од"];
let current = 2;

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› ⏮ Өмнөх: Хавар› ▶️ Одоо: Тал нутаг› ⏭ Дараагийн: Бороо

ХЭРЭВ let current = 3; БОЛ

console› ⏮ Өмнөх: Тал нутаг› ▶️ Одоо: Бороо› ⏭ Дараагийн: Од

💡 Индекс нь тоо — түүн дээр нэмж, хасаж болно: songs[current - 1], songs[current + 1].

Хэрэглэх: [current] · current - 1 · current + 1

ДАСГАЛ 3

Ирцийн жагсаалт ✋

Сурагч бүрийн нэрийг дугаартай нь хэвлэ — дугаар 1-ээс эхэлнэ (индекс 0-ээс!). Төгсгөлд нь хэдэн сурагч байгааг хэвлэ.

ЭХЛЭХ КОД — хуулж ав

const students = ["Бат", "Сараа", "Тэмүүлэн", "Ану", "Болд"];

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› 1. Бат› 2. Сараа› 3. Тэмүүлэн› 4. Ану› 5. Болд› Нийт 5 сурагч

💡 for-оор i = 0-ээс i < students.length хүртэл. Дугаар = i + 1, нэр = students[i].

Хэрэглэх: for · i < length · i + 1

ДАСГАЛ 4

Цэс шинэчлэх 🍽️

Өнөөдөр банштай шөл дууссан тул тэр хоолыг «Бууз»-аар соль. Дараа нь цэсийг НЭГ мөрөнд « · »-ээр тусгаарлан хэвлэ.

ЭХЛЭХ КОД — хуулж ав

const menu = ["Цуйван", "Хуушуур", "Банштай шөл", "Гурилтай шөл"];

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› Цуйван · Хуушуур · Бууз · Гурилтай шөл

💡 Банштай шөл хэддүгээр индекст байна? Солиод, дараа нь мөрөө давталтаар бүтээ: эхний хоолны өмнө « · » тавихгүй (өрөөний дугаарын дасгал шиг).

Хэрэглэх: arr[i] = … · for · if

ДАСГАЛ 5

Шалгалтын дундаж 📝

Ангийн шалгалтын оноонуудын нийлбэр ба дундажийг хэвлэ.

ЭХЛЭХ КОД — хуулж ав

const scores = [85, 92, 78, 64, 96, 80];

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› Нийлбэр: 495› Дундаж: 82.5

💡 Нийлбэрийг 0-ээс эхлүүлээд давталт бүрт scores[i]-г нэм. Дундаж = нийлбэр / scores.length.

Хэрэглэх: for · sum = sum + scores[i] · / length

ДАСГАЛ 6

Хамгийн хүйтэн өдөр 🥶

temps[i] нь days[i] өдрийн температур. Хамгийн хүйтэн өдрийн нэр ба хэмийг хэвлэ.

ЭХЛЭХ КОД — хуулж ав

const days = ["Даваа", "Мягмар", "Лхагва", "Пүрэв", "Баасан"];
const temps = [-12, -18, -25, -9, -15];

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› 🥶 Хамгийн хүйтэн: Лхагва (-25°)

💡 Хоёр массивын ижил индекс = нэг өдөр. Хамгийн хүйтний ИНДЕКСИЙГ хадгал (0-ээс эхэл). temps[i] түүнээс бага бол индексээ шинэчил.

Хэрэглэх: хоёр массив · ижил индекс · for · if

ДАСГАЛ 7

Санал тоолох 🗳️

Ангийн даргын сонгуулийн саналууд. Бат хэдэн санал авсныг, нийт хэдэн санал байгааг хэвлэ.

ЭХЛЭХ КОД — хуулж ав

const votes = ["Бат", "Сараа", "Бат", "Ану", "Бат", "Сараа", "Ану", "Бат"];

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› Бат: 4 санал› Нийт: 8 санал

💡 Тоолуурыг 0-ээс эхлүүл. votes[i] нь "Бат" бол 1 нэм. Нийт саналын тоог тоолох хэрэггүй — length байна.

Хэрэглэх: for · if · === · тоолуур

ДАСГАЛ 8

Автобуснаас буух 🚌

Хүмүүс автобусанд массивын дарааллаар орсон. Сүүлд орсон нь хаалганд хамгийн ойр тул түрүүлж бууна. Сүүлээс нь эхлэн хэвлэ.

ЭХЛЭХ КОД — хуулж ав

const bus = ["Бат", "Сараа", "Тэмүүлэн", "Ану"];

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› 🚪 Ану буулаа› 🚪 Тэмүүлэн буулаа› 🚪 Сараа буулаа› 🚪 Бат буулаа

💡 Сүүлийн индексээс (bus.length - 1) эхэлж, i >= 0 байх хооронд i--.

Хэрэглэх: for · i-- · length - 1

ДАСГАЛ 9

Тавиураас хайх 🔍

wanted бараа хэддүгээр тавиур дээр байгааг (1-ээс тоолно) хэвлэ. Байхгүй бол «😢 … олдсонгүй». wanted-ийг өөрчлөөд бас шалга.

ЭХЛЭХ КОД — хуулж ав

const shelf = ["🍎", "🥛", "🍞", "🧀", "🍌", "🥚"];
const wanted = "🧀";

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› 🧀 4-р тавиур дээр байна

ХЭРЭВ const wanted = "🍫"; БОЛ

console› 😢 🍫 олдсонгүй

ХЭРЭВ const wanted = "🍎"; БОЛ

console› 🍎 1-р тавиур дээр байна

💡 Олдсон индексийг хадгалах хувьсагчийг -1-ээс эхлүүл ("байхгүй" гэсэн утга). Давталтын дараа -1 хэвээр бол олдоогүй.

Хэрэглэх: for · if · === · -1

ДАСГАЛ 10

Тест засах ✅

correct — зөв хариултууд, answers — сурагчийн хариултууд. Буруу хариулсан асуулт бүрийн дугаарыг (1-ээс) хэвлээд, төгсгөлд нь оноог «7 / 10» гэж хэвлэ.

ЭХЛЭХ КОД — хуулж ав

const correct = ["A", "C", "B", "D", "A", "B", "C", "D", "A", "C"];
const answers = ["A", "C", "D", "D", "A", "B", "A", "D", "B", "C"];

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› ❌ 3-р асуулт› ❌ 7-р асуулт› ❌ 9-р асуулт› Оноо: 7 / 10

💡 Хоёр массивыг НЭГ давталтаар зэрэг гүй: correct[i] ба answers[i]. Таарахгүй бол дугаарыг (i + 1) хэвлэ, таарвал оноог нэм.

Хэрэглэх: хоёр массив · ижил индекс · for · if / else
