Media query — бие даах 10 дасгал

Хичээлийн дараа өөрөө хий. Гулсуураар ЗОРИЛГО-г утас, таблет, компьютерт хар.

ЯАЖ ХИЙХ ВЭ

  1. Дасгалын «Эхлэх код»-ыг нээгээд өөрийн шинэ HTML файлд хуул. Тэнд media query байхгүй.
  2. ЗОРИЛГО-той адилхан болтол media query-гээ хамгийн доор нь нэм.
  3. Өөрийн хуудсаа Cmd + Shift + M-ээр 375 · 700 · 1000px дээр шалга.
  4. Гацвал л «Хариулт»-ыг нээ.
