DOM — 3 дасгал

getElementById · input.value · textContent · onclick · Number()

  1. HTML-ийг хуулж index.html-даа тавь. JavaScript-ээ script.js-д өөрөө бич.
  2. Хуудсаа нээгээд жишээ утгуудыг бичиж, товчоо дар. «Товч дарсны дараа» зурагтай адилхан болох ёстой.
  3. Алдаа гарвал Console-оо нээ: Cmd + Option + J
ДАСГАЛ 1Амархан

Бүтэн нэр

HTML — хуулж ав

<h1 id="greeting">Сайн уу!</h1>

<input id="firstName" type="text" placeholder="Нэр" />
<input id="lastName" type="text" placeholder="Овог" />
<button onclick="showName()">Харуулах</button>

ДАСГАЛ 3Хэцүү

Хоолны төлбөр хуваах

Найзуудтайгаа хоол идлээ. Нийт төлбөр, гарын мөнгөний хувь, хүний тоог бичээд товч дарахад гарын мөнгө, нийт дүн, нэг хүнд ногдох мөнгө гурвуулаа гарна.

HTML — хуулж ав

<h1 id="each">Нэг хүн: ?</h1>

<input id="billInput" type="number" placeholder="Нийт төлбөр" />
<input id="tipInput" type="number" placeholder="гарын мөнгө (%)" />
<input id="peopleInput" type="number" placeholder="Хүний тоо" />
<button onclick="split()">Хуваах</button>

<p id="tip">гарын мөнгө: ?</p>
<p id="total">Нийт: ?</p>
