for давталт — дахиад 10 дасгал

Зөвхөн for · if · % · && · || · prompt · `${ }` · console.log

ЭХЛЭХ

  1. Шинэ хавтас нээгээд index.html, script.js гэсэн хоёр файл үүсгэ.
  2. index.html-д доорх кодыг хуул. <script> нь body-гийн хамгийн доор байна.
  3. Дасгал бүрийг script.js-д бич. Дараагийн дасгал руу шилжихдээ өмнөхөө /* */-аар comment болго.
  4. Console-оо нээ: Cmd + Option + J. Алдаа гарвал улаан мөрийг унш.
<!doctype html>
<html lang="mn">
  <head>
    <meta charset="UTF-8" />
    <title>JS дасгал</title>
  </head>
  <body>
    <h1>JS дасгал</h1>

    <script src="script.js"></script>
  </body>
</html>

ДАСГАЛ 7

Факториал ❗

n! (n факториал) гэдэг нь 1-ээс n хүртэлх бүх тоонуудын ҮРЖВЭР: 5! = 1 × 2 × 3 × 4 × 5. n-ийг prompt-оор асуугаад n!-ийг хэвлэ.

ЖИШЭЭ 1

prompt

Аль тооны факториалыг олох вэ?

5
→
console› 5! = 120

ЖИШЭЭ 2

prompt

Аль тооны факториалыг олох вэ?

7
→
console› 7! = 5040

💡 Нийлбэр 0-ээс эхэлдэг. Харин үржвэр 0-ээс эхэлбэл юу болох вэ? Үржвэрийн хувьсагч хэднээс эхлэх ёстойг бод.

Хэрэглэх: prompt · Number() · for · `${ }`
