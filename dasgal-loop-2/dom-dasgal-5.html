DOM × JavaScript — 10 дасгал

getElementById · input.value · textContent · onclick · Number() · let

  1. HTML-ийг хуулж index.html-даа тавь. JavaScript-ээ script.js-д өөрөө бич.
  2. Хуудсаа нээгээд жишээ утгуудыг бичиж, товчоо дар. «Шалгах жишээнүүд»-ийг нэг нэгээр нь хийж үз — бүгд зөв гарах ёстой.
  3. Алдаа гарвал Console-оо нээ: Cmd + Option + J

DOM × JS — ҮРГЭЛЖ ЭНЭ 4 АЛХАМ

<!-- HTML: JS-ээс олох элементэд id өг -->
<h1 id="title">Хот</h1>
<input id="cityInput" type="text" />
<button onclick="show()">Харуулах</button>

// JS
// 1. ОЛОХ — id-аар нь
const title = document.getElementById("title");
const cityInput = document.getElementById("cityInput");

// 2. ДАРАХАД — товч дарахад энэ функц ажиллана
function show() {
  // 3. УНШИХ — input-ээс .value
  const city = cityInput.value;

  // 4. БИЧИХ — дэлгэц рүү .textContent
  title.textContent = `Хот: ${city}`;
}
  • .value — зөвхөн input-д. .textContent — h1, p гэх мэт текстэнд.
  • input-ийн утгыг функцийн ДОТОР унш. Гадна уншвал хуудас нээгдэх үеийн хоосон утгыг авна.
  • input.value нь текст: "2" + "3" = "23". Тоо хэрэгтэй бол Number().
  • Товч дарах бүрт хадгалагдах утга (like, оноо) — функцийн ГАДНА let.
