ДАВТЛАГА · DOM + JAVASCRIPT

DOM × JavaScript — 5 сорилттой дасгал

getElementById · .value · .textContent · onclick · Number() · if/else · for · DOM элемент үүсгэх

  1. Дасгал бүрийн HTML-ийг index.html-даа хуул. JavaScript-ээ script.js файлд өөрөө бич.
  2. Шалгах жишээнүүдийг нэг нэгээр нь турш. Зөвхөн эхний жишээг ажиллуулаад зогсохгүй бүх нөхцөлийг шалга.
  3. Алдаа гарвал browser Console-оо нээ: Cmd + Option + J (Mac) эсвэл Ctrl + Shift + J (Windows).
  4. Шийдлийг шууд хайхгүйгээр эхлээд өөрөө бод. Доорх зөвлөмж нь чиглэл өгөх болохоос бэлэн код биш.

САНАХ 4 АЛХАМ

// 1. ОЛОХ
const title = document.getElementById("title");
const input = document.getElementById("myInput");

// 2. ТОВЧ ДАРАХАД АЖИЛЛАХ ФУНКЦ
function show() {
  // 3. УНШИХ
  const value = input.value;

  // 4. ДЭЛГЭЦЭНД ХАРУУЛАХ
  title.textContent = value;
}
  • .value нь input-ээс утга уншина; .textContent нь элемент доторх текстийг өөрчилнө.
  • input.value бол текст. Тоогоор бодохын өмнө Number() ашигла.
  • Товч дарах хооронд хадгалагдах тоо/төлөвийг функцийн гадна let-ээр зарла.
  • Олон элемент үүсгэхдээ document.createElement(), жагсаалтад нэмэхдээ appendChild() ашиглаж болно.
ДАСГАЛ 1ТҮВШИН 1

🛒 Худалдааны сагс

Бараа сонгож, тоо ширхэг оруулаад нийт үнийг тооцоол. 5 ба түүнээс олон бараа авбал 10% хөнгөлөлт үзүүл.

HTML — хуулж ав

<h1 id="cart">🛒 Сагс хоосон</h1>

<select id="product">
  <option value="5000">Дэвтэр — 5000₮</option>
  <option value="3000">Үзэг — 3000₮</option>
  <option value="12000">Ном — 12000₮</option>
</select>

<input id="quantity" type="number" placeholder="Тоо ширхэг">
<button onclick="checkout()">Захиалах</button>

ХИЙХ ДААЛГАВАР

  • Сонгосон барааны үнийг product.value-аас авч, тоо ширхэгтэй үржүүл.
  • Тоо ширхэг 5 буюу түүнээс их бол нийт үнээс 10% хас.
  • Тоо ширхэг хоосон, 0 эсвэл сөрөг бол алдааны мессеж харуул.
  • Нийт үнэ болон хөнгөлөлт авсан эсэхийг дэлгэцэнд харуул.

ШАЛГАХ ЖИШЭЭНҮҮД

БАРААТООГАРАХ ЁСТОЙ
Дэвтэр2Нийт: 10,000₮
Үзэг5Нийт: 13,500₮ (10% хөнгөлөлттэй)
Ном3Нийт: 36,000₮
Дэвтэр0Алдааны мессеж

💡 Зөвлөмж: Number(), if/else, үржих болон хөнгөлөлтийн тооцоолол ашигла.

ДАСГАЛ 2ТҮВШИН 2

🎯 Тоо таах тоглоом

Компьютер 1–20 хооронд нууц тоо сонгоно. Хэрэглэгч зөв тоог олох хүртлээ таамаглана.

HTML — хуулж ав

<h1 id="message">🎯 1–20 хооронд тоо таа!</h1>
<p id="attempts">Оролдлого: 0</p>

<input id="guess" type="number" placeholder="Таамагласан тоо">
<button onclick="checkGuess()">Таах</button>
<button onclick="restart()">Дахин эхлэх</button>

ХИЙХ ДААЛГАВАР

  • Math.random() ашиглан 1–20 хооронд бүхэл тоо үүсгэ.
  • Таамаг нууц тооноос бага бол “⬆️ Илүү том тоо!”, их бол “⬇️ Илүү бага тоо!” гэж харуул.
  • Оролдлого бүрийн дараа оролдлогын тоог 1-ээр нэм.
  • Зөв таасны дараа дахин таах товчийг ажиллахгүй болгох эсвэл дараагийн таамгийг үл тоо.
  • “Дахин эхлэх” дарахад шинэ нууц тоо үүсгэж, оролдлогыг 0 болго.

ШАЛГАХ ЖИШЭЭНҮҮД

НӨХЦӨЛГАРАХ ЁСТОЙ
Таамаг 5, нууц тоо 12⬆️ Илүү том тоо!
Таамаг 18, нууц тоо 12⬇️ Илүү бага тоо!
Таамаг 12, нууц тоо 12🎉 Зөв таалаа!
Дахин эхлэхШинэ тоглоом, оролдлого: 0

💡 Зөвлөмж: Math.floor(Math.random() * 20) + 1, let, if/else ашигла. Нууц тоо болон оролдлогын тоог функцийн гадна хадгал.

ДАСГАЛ 3ТҮВШИН 3

📝 Даалгаврын жагсаалт

Хэрэглэгч даалгавар нэмэх, дууссан гэж тэмдэглэх, устгах боломжтой жижиг To-do List хийнэ.

HTML — хуулж ав

<h1>📝 Миний даалгаврууд</h1>
<input id="taskInput" type="text" placeholder="Даалгавраа бич">
<button onclick="addTask()">Нэмэх</button>

<p id="status">Нийт: 0 | Дууссан: 0</p>
<ul id="taskList"></ul>

ХИЙХ ДААЛГАВАР

  • Input хоосон байвал даалгавар нэмэхгүй, алдааны мессеж харуул.
  • document.createElement("li") ашиглан шинэ даалгавар үүсгэж жагсаалтад нэм.
  • Даалгавар бүрд “Дууссан” болон “Устгах” гэсэн товч нэм.
  • “Дууссан” дарахад тухайн даалгаврын текст зураастай болно.
  • “Устгах” дарахад зөвхөн тухайн даалгавар арилна.
  • Нийт даалгавар болон дууссан даалгаврын тоог үйлдэл бүрийн дараа шинэчил.

ШАЛГАХ ЖИШЭЭНҮҮД

ҮЙЛДЭЛГАРАХ ЁСТОЙ
“Хичээл хийх” нэмэхНийт: 1 | Дууссан: 0
“Ном унших” нэмэхНийт: 2 | Дууссан: 0
Эхний даалгаврыг дуусгахНийт: 2 | Дууссан: 1
Хоёр дахь даалгаврыг устгахНийт: 1 | Дууссан: 1

💡 Зөвлөмж: createElement(), appendChild(), .remove(), classList.toggle() ашигла. Хэрэглэгчийн бичсэн текстийг textContent-оор оруул.

📊 Шалгалтын оноо тооцоологч

Гурван шалгалтын оноог авч дундажийг тооцоолон, дүнд нь тохирсон үнэлгээ харуул.

HTML — хуулж ав

<h1>📊 Шалгалтын тайлан</h1>
<input id="score1" type="number" placeholder="1-р шалгалт (0–100)">
<input id="score2" type="number" placeholder="2-р шалгалт (0–100)">
<input id="score3" type="number" placeholder="3-р шалгалт (0–100)">

<button onclick="calculate()">Тооцоолох</button>
<h2 id="result">Үр дүн энд гарна</h2>
<p id="grade"></p>

ХИЙХ ДААЛГАВАР

  • Гурван оноог уншиж, тоо болгон хувирга.
  • Input бүр бөглөгдсөн эсэх, оноо тус бүр 0–100 хооронд байгаа эсэхийг шалга.
  • Дундаж оноог нэг орны нарийвчлалтай харуул.
  • Дундаж оноонд тохирох үнэлгээ харуул.

ДАСГАЛ 5ТҮВШИН 4

💰 Халаасны мөнгөний менежер

Орлого, зарлага бүртгэж, мөнгөний үлдэгдлээ удирдах жижиг апп хий.

HTML — хуулж ав

<h1>💰 Миний хэтэвч</h1>
<p id="balance">Үлдэгдэл: 0₮</p>
<p id="history">Одоогоор гүйлгээ байхгүй.</p>

<input id="amount" type="number" placeholder="Мөнгөн дүн">
<button onclick="addMoney()">➕ Орлого</button>
<button onclick="spendMoney()">➖ Зарлага</button>
<button onclick="resetWallet()">🔄 Дахин эхлэх</button>

ХИЙХ ДААЛГАВАР

  • Эхний үлдэгдлийг функцийн гадна let balance = 0 гэж зарла.
  • Орлого нэмэх товч мөнгийг үлдэгдэлд нэмнэ; зарлага хасах товч үлдэгдлээс хасна.
  • Зарлага үлдэгдлээс их бол гүйлгээг хийхгүй, алдааны мессеж харуул.
  • Мөнгөн дүн хоосон, 0 эсвэл сөрөг бол гүйлгээ хийхгүй.
  • Үлдэгдэл болон хамгийн сүүлийн гүйлгээний төрөл, дүнг үйлдэл бүрийн дараа шинэчил.
  • “Дахин эхлэх” дарахад үлдэгдэл 0 болж, гүйлгээний мэдээлэл цэвэрлэгдэнэ.

ШАЛГАХ ЖИШЭЭНҮҮД

ҮЙЛДЭЛГАРАХ ЁСТОЙ

5,000₮ орлогоҮлдэгдэл: 43,000₮
Дахин эхлэхҮлдэгдэл: 0₮

💡 Зөвлөмж: үлдэгдлийг хадгалах нэг хувьсагч ашигла. Үлдэгдэл шинэчлэх кодыг тусдаа функц болгож, орлого/зарлагын функцээс дуудаж болно.
