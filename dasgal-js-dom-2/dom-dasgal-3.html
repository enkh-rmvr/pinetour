  1. HTML-ийг хуулж index.html-даа тавь. JavaScript-ээ script.js-д өөрөө бич.

ДАСГАЛ 8Хэцүү

Онооны самбар

Хоёр багийн тоглолт. «🔴 +1» дарахад улааны оноо, «🔵 +1» дарахад цэнхэрийн оноо нэмэгдэж h1 дээр «3 : 2» гэж гарна. «Дахин эхлэх» дарахад «0 : 0» болно.

HTML — хуулж ав

<h1 id="score">0 : 0</h1>

<button id="redButton" onclick="addRed()">🔴 +1</button>
<button id="blueButton" onclick="addBlue()">🔵 +1</button>
<button id="resetButton" onclick="resetScore()">Дахин эхлэх</button>
