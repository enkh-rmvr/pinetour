if / else — 10 дасгал

> < >= <= === !== · if · else · else if · && || !

  1. HTML-ийг хуулж index.html-даа тавь. JavaScript-ээ script.js-д өөрөө бич.
  2. Хуудсаа нээгээд жишээ утгуудыг бичиж, товчоо дар. «Шалгах жишээнүүд»-ийг нэг нэгээр нь бичиж үз — бүгд зөв гарах ёстой.
  3. Алдаа гарвал Console-оо нээ: Cmd + Option + J

Дэлгүүрийн хямдрал

Худалдан авалтын дүнг бичээд товч дарахад хямдрал, хүргэлт, төлөх мөнгө гарна. Хямдрал: 100000₮ ба түүнээс дээш бол 10%, 50000₮ ба түүнээс дээш бол 5%, бусад үед хямдралгүй. Хүргэлт: 30000₮ ба түүнээс дээш бол үнэгүй, бусад үед 5000₮. Төлөх = дүн − хямдрал + хүргэлт.
