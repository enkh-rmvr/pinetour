Параметртэй функц — 10 дасгал

function нэр(параметр) · if / else if · for · массив параметр · console.log

ЭХЛЭХ

  1. Шинэ хавтас нээгээд index.html, script.js гэсэн хоёр файл үүсгэ.
  2. index.html-д доорх кодыг хуул. <script> нь body-гийн хамгийн доор байна.
  3. Дасгал бүрийг script.js-д бич. Дараагийн дасгал руу шилжихдээ өмнөхөө /* */-аар comment болго.
  4. Console-оо нээ: Cmd + Option + J. Алдаа гарвал улаан мөрийг унш.
<!doctype html>
<html lang="mn">
  <head>
    <meta charset="UTF-8" />
    <title>JS дасгал</title>
  </head>
  <body>
    <h1>JS дасгал</h1>

    <script src="script.js"></script>
  </body>
</html>
ДАСГАЛ 1

Цагаар мэндлэх ☀️🌙

greetByHour(name, hour) функц бич. Цаг 12-оос бага бол өглөө, 18-аас бага бол өдөр, бусад үед орой гэж мэндэлнэ.

ДУУДАХ КОД — script.js-ийн хамгийн доор хуул, функцээ ДЭЭР нь бич

greetByHour("Бат", 9);
greetByHour("Сараа", 14);
greetByHour("Ану", 20);

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› ☀️ Өглөөний мэнд, Бат!› 🌤 Өдрийн мэнд, Сараа!› 🌙 Оройн мэнд, Ану!

💡 Хоёр параметр: name, hour. hour-оор нь if / else if / else-ээр аль мэндчилгээ болохыг шийдээд, name-ийг текст дотор оруул.

Хэрэглэх: 2 параметр · if · else if · else · `${ }`

Хэрэглэх: 1 параметр · for · текст нэмэх

Хэрэглэх: 1 параметр · for · i--

ДУУДАХ КОД — script.js-ийн хамгийн доор хуул, функцээ ДЭЭР нь бич

💡 Давталт 1-ээс upTo хүртэл. Мөр бүрт n x i = n * i.

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› 2 4 6 8 10› 16 18 20

Хэрэглэх: 2 параметр · for · if · %

ДУУДАХ КОД — script.js-ийн хамгийн доор хуул, функцээ ДЭЭР нь бич

ДАСГАЛ 10

Ирц бүртгэл ✅

attendance(names, present) функц бич. names — нэрс, present — ирсэн эсэх (true / false). Хүн бүрийг ✅ / ❌-тэй хэвлээд, төгсгөлд нь ирцийг «3 / 4» гэж хэвлэнэ.

ДУУДАХ КОД — script.js-ийн хамгийн доор хуул, функцээ ДЭЭР нь бич

attendance(["Бат", "Сараа", "Ану", "Болд"], [true, false, true, true]);

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› ✅ Бат› ❌ Сараа› ✅ Ану› ✅ Болд› Ирц: 3 / 4

💡 Хоёр массивыг нэг давталтаар зэрэг гүй: names[i] ба present[i]. present[i] нь true / false — шууд if (present[i]) гэж бичиж болно.

Хэрэглэх: 2 массив параметр · for · if · тоолуур
