Параметртэй функц — дахиад 10 дасгал

параметр · if / else if · for · массив параметр · давталт дотор давталтгүй · console.log

ЭХЛЭХ

  1. Шинэ хавтас нээгээд index.html, script.js гэсэн хоёр файл үүсгэ.
  2. index.html-д доорх кодыг хуул. <script> нь body-гийн хамгийн доор байна.
  3. Дасгал бүрийг script.js-д бич. Дараагийн дасгал руу шилжихдээ өмнөхөө /* */-аар comment болго.
  4. Console-оо нээ: Cmd + Option + J. Алдаа гарвал улаан мөрийг унш.
<!doctype html>
<html lang="mn">
  <head>
    <meta charset="UTF-8" />
    <title>JS дасгал</title>
  </head>
  <body>
    <h1>JS дасгал</h1>

    <script src="script.js"></script>
  </body>
</html>
ДАСГАЛ 1

Цахилгааны төлбөр ⚡

electricityBill(kwh) функц бич. Эхний 100 кВт·ц нь 150₮, 101–200 дахь нь 200₮, 200-аас дээших нь 300₮. Жишээ нь 150 кВт·ц = 100 × 150 + 50 × 200.

ДУУДАХ КОД — script.js-ийн хамгийн доор хуул, функцээ ДЭЭР нь бич

electricityBill(80);
electricityBill(150);
electricityBill(260);
electricityBill(100);

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› ⚡ 80 кВт·ц → 12000₮› ⚡ 150 кВт·ц → 25000₮› ⚡ 260 кВт·ц → 53000₮› ⚡ 100 кВт·ц → 15000₮

💡 Гурван тохиолдол: kwh ≤ 100, kwh ≤ 200, бусад. Хоёр дахь тохиолдолд эхний 100-ийн мөнгө (15000) + үлдсэн хэсэг × 200.

Хэрэглэх: 1 параметр · if · else if · шатлалтай тооцоо

ДАСГАЛ 2

Сүүлээс нь нэг мөрөнд

reverseLine(names) функц бич. Массивыг СҮҮЛЭЭС нь эхлэн нэг мөрөнд « · »-ээр тусгаарлан хэвлэнэ. Хоосон массив бол «(хоосон)».

ДУУДАХ КОД — script.js-ийн хамгийн доор хуул, функцээ ДЭЭР нь бич

reverseLine(["Бат", "Сараа", "Ану", "Болд"]);
reverseLine(["Өглөө", "Өдөр"]);
reverseLine([]);

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› Болд · Ану · Сараа · Бат› Өдөр · Өглөө› (хоосон)

💡 Давталт names.length - 1-ээс 0 хүртэл. Эхний нэрийн өмнө « · » тавихгүй. Давталтын дараа мөр хоосон хэвээр бол «(хоосон)».

Хэрэглэх: массив параметр · for · i-- · if

ДАСГАЛ 3

Бүх байрлалыг олох 🔍

findAll(items, target) функц бич. target хэддүгээр байранд (1-ээс тоолно) байгааг бүгдийг нь таслалаар хэвлэнэ. Огт байхгүй бол «олдсонгүй».

ДУУДАХ КОД — script.js-ийн хамгийн доор хуул, функцээ ДЭЭР нь бич

findAll(["🍎", "🍌", "🍎", "🍇", "🍎"], "🍎");
findAll(["🍎", "🍌", "🍎", "🍇", "🍎"], "🍇");
findAll(["🍎", "🍌"], "🥝");

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› 🍎 → 1, 3, 5› 🍇 → 4› 🥝 → олдсонгүй

💡 Олдох бүрт байрлалыг (i + 1) мөрөнд нэм — эхнийхийн өмнө таслалгүй. Давталтын дараа мөр хоосон бол олдоогүй.

Хэрэглэх: 2 параметр · for · if · === · таслал

ДАСГАЛ 4

Бага, их, дундаж — нэг давталтаар

stats(numbers) функц бич. НЭГ л давталтаар хамгийн бага, хамгийн их тоо болон дундажийг олж, нэг мөрөнд хэвлэнэ. Хасах тоонууд ч зөв ажиллах ёстой.

ДУУДАХ КОД — script.js-ийн хамгийн доор хуул, функцээ ДЭЭР нь бич

stats([4, 9, 2, 5]);
stats([-3, -7, -2]);

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› Бага: 2 · Их: 9 · Дундаж: 5› Бага: -7 · Их: -2 · Дундаж: -4

💡 Бага, их хоёулаа numbers[0]-оос эхэлнэ (0-ээс биш!). Нийлбэр 0-ээс. Давталт бүрт гурвыг нь зэрэг шинэчил.

Хэрэглэх: массив параметр · for · if · 3 хувьсагч зэрэг

ДАСГАЛ 5

Секундыг цаг болгох ⏱

formatTime(seconds) функц бич. Секундыг «1 цаг 2 минут 5 секунд» болгоно. 0-тэй хэсгийг бичихгүй (7200 → «2 цаг»). Бүгд 0 бол «0 секунд».

ДУУДАХ КОД — script.js-ийн хамгийн доор хуул, функцээ ДЭЭР нь бич

formatTime(3725);
formatTime(90);
formatTime(7200);
formatTime(45);
formatTime(0);

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› ⏱ 1 цаг 2 минут 5 секунд› ⏱ 1 минут 30 секунд› ⏱ 2 цаг› ⏱ 45 секунд› ⏱ 0 секунд

💡 1 цаг = 3600 секунд. Цаг = (seconds − seconds % 3600) / 3600. Үлдэгдэл (seconds % 3600)-аас минутыг яг ийм аргаар. Хэсэг бүрийг 0-ээс их бол л текстэд нэм.

Хэрэглэх: 1 параметр · % · / · if · текст бүтээх

ДАСГАЛ 6

Хүрээ зурах 🖼

frame(width, height) функц бич. Ирмэг нь 🟦, дотор нь ⬜ хүрээ зурна. Давталт дотор давталт ХЭРЭГГҮЙ.

ДУУДАХ КОД — script.js-ийн хамгийн доор хуул, функцээ ДЭЭР нь бич

frame(4, 3);
frame(5, 4);

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› 🟦🟦🟦🟦› 🟦⬜⬜🟦› 🟦🟦🟦🟦› 🟦🟦🟦🟦🟦› 🟦⬜⬜⬜🟦› 🟦⬜⬜⬜🟦› 🟦🟦🟦🟦🟦

💡 Мөр 2 л янз: дүүрэн (🟦🟦🟦🟦) ба хөндий (🟦⬜⬜🟦). Эхлээд хоёуланг нь давталтаар бэлд. Дараа нь height удаа давтаж, эхний эсвэл сүүлийн мөр бол дүүрэн, бусад үед хөндийг хэвлэ.

Хэрэглэх: 2 параметр · 3 давталт ДАРААЛАН · if · ||

ДАСГАЛ 7

Дарааллаараа юу? 📈

isSorted(numbers) функц бич. Тоонууд өсөх дарааллаар (ижил байж болно) байвал ✅. Үгүй бол ХАМГИЙН ЭХНИЙ эвдэрсэн газрыг хэвлэнэ.

ДУУДАХ КОД — script.js-ийн хамгийн доор хуул, функцээ ДЭЭР нь бич

isSorted([1, 3, 5, 9]);
isSorted([2, 4, 9, 7, 10]);
isSorted([5, 3, 1]);
isSorted([1, 1, 2]);

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› ✅ Өсөх дарааллаар› ❌ 4-р тоо (7) өмнөхөөсөө (9) бага› ❌ 2-р тоо (3) өмнөхөөсөө (5) бага› ✅ Өсөх дарааллаар

💡 Хөрш хоёрыг харьцуул: numbers[i] ба numbers[i - 1], i 1-ээс эхэлнэ. Эвдэрсэн байрлалыг -1-ээс эхэлсэн хувьсагчид хадгал — зөвхөн анх удаа (хувьсагч -1 хэвээр байхад).

Хэрэглэх: массив параметр · for · numbers[i - 1] · -1

ДАСГАЛ 8

Дунджаас дээш ⭐

aboveAverage(names, scores) функц бич. Ангийн дундаж оноог хэвлээд, дунджаас ИХ оноотой сурагчдыг нэр, оноотой нь хэвлэнэ.

ДУУДАХ КОД — script.js-ийн хамгийн доор хуул, функцээ ДЭЭР нь бич

aboveAverage(["Бат", "Сараа", "Ану", "Болд", "Тэмүүлэн"], [72, 95, 64, 88, 81]);

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› Дундаж: 80› ⭐ Сараа (95)› ⭐ Болд (88)› ⭐ Тэмүүлэн (81)

💡 Эхний давталтаар нийлбэр → дундаж. Дундажийг хэвлэ. Хоёр дахь давталтаар scores[i] > дундаж бол names[i]-г хэвлэ. Давталт дотор давталт биш — нэгнийх нь дараа нөгөө.

Хэрэглэх: 2 массив параметр · 2 давталт ДАРААЛАН · if

ДАСГАЛ 9

Баримт + хөнгөлөлт 🧾

receipt(items, prices, counts) функц бич. Бараа бүрийн мөр, нийт дүнг хэвлэнэ. Нийт 20000₮ ба түүнээс их бол 10% хөнгөлөлтийн мөр нэмнэ. Төгсгөлд төлөх дүн.

ДУУДАХ КОД — script.js-ийн хамгийн доор хуул, функцээ ДЭЭР нь бич

receipt(["🥟 Бууз", "🥤 Кола", "🍰 Бялуу"], [1500, 3000, 6000], [10, 2, 1]);
receipt(["☕ Кофе"], [5000], [2]);

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› 🥟 Бууз × 10 = 15000₮› 🥤 Кола × 2 = 6000₮› 🍰 Бялуу × 1 = 6000₮› Нийт: 27000₮› Хөнгөлөлт 10%: -2700₮› Төлөх: 24300₮› ☕ Кофе × 2 = 10000₮› Нийт: 10000₮› Төлөх: 10000₮

💡 3 массивыг нэг индексээр уншина: items[i], prices[i], counts[i]. Давталтын дараа нийт ≥ 20000 эсэхийг шалгаад, хөнгөлөлт = нийт × 10 / 100.

Хэрэглэх: 3 массив параметр · for · if · %

ДАСГАЛ 10

Тоо таах — бэлэн оролдлогууд 🎯

guessGame(secret, guesses) функц бич. Оролдлого бүрт «илүү их / бага / Таалаа!» хэвлэнэ. Таасны дараах оролдлогуудыг АЛГАСНА. Төгсгөлд хэддэх оролдлогоор таасныг, эсвэл таагаагүйг хэвлэнэ.

ДУУДАХ КОД — script.js-ийн хамгийн доор хуул, функцээ ДЭЭР нь бич

guessGame(37, [50, 25, 37, 40]);
guessGame(10, [5, 8]);

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› 50 → илүү бага тоо ⬇️› 25 → илүү их тоо ⬆️› 37 → 🎉 Таалаа!› ✅ 3 оролдлогоор› 5 → илүү их тоо ⬆️› 8 → илүү их тоо ⬆️› 😢 Таасангүй. Нууц тоо: 10

💡 Таасан эсэхийг true / false-оор хадгал (эхэндээ false). Давталт бүрт таагаагүй үед л шалга, оролдлогын тоог нэм. Давталтын дараа энэ хувьсагчаар аль мөрийг хэвлэхээ шийд.

Хэрэглэх: 2 параметр · for · if · else if · true / false · тоолуур
