ЭХЛЭХ

  1. Шинэ хавтас нээгээд index.html, script.js гэсэн хоёр файл үүсгэ.

  4. Console-оо нээ: Cmd + Option + J. Алдаа гарвал улаан мөрийг унш.

  <head>
    <meta charset="UTF-8" />

ATM — мөнгө задлах

Авах мөнгийг асуугаад 20000, 10000, 5000, 1000-ын дэвсгэртээр хэдэн ширхэг өгөхийг бич. Том дэвсгэртээс эхэл.

ЖИШЭЭ

prompt

Хэдэн төгрөг авах вэ?

47000
→
console› 20000₮ × 2› 10000₮ × 0› 5000₮ × 1› 1000₮ × 2

💡 Ширхэг = (мөнгө − мөнгө % 20000) / 20000. Үлдэгдэл = мөнгө % 20000. Дараагийн дэвсгэрт рүү үлдэгдлээ дамжуул.

Хэрэглэх: % · − · /

Хариулт — эхлээд өөрөө хий
const amount = Number(prompt("Хэдэн төгрөг авах вэ?"));

const n20 = (amount - amount % 20000) / 20000;
const rest20 = amount % 20000;

const n10 = (rest20 - rest20 % 10000) / 10000;
const rest10 = rest20 % 10000;

const n5 = (rest10 - rest10 % 5000) / 5000;
const rest5 = rest10 % 5000;

const n1 = (rest5 - rest5 % 1000) / 1000;

console.log("20000₮ × " + n20);
console.log("10000₮ × " + n10);
console.log("5000₮ × " + n5);
console.log("1000₮ × " + n1);
