ХИЧЭЭЛ 09 · JAVASCRIPT

JavaScript — 10 дасгал

Хувьсагч · prompt · Number() · console.log · alert · арифметик

ЭХЛЭХ

  1. Шинэ хавтас нээгээд index.html, script.js гэсэн хоёр файл үүсгэ.
  2. index.html-д доорх кодыг хуул. <script> нь body-гийн хамгийн доор байна.
  3. Дасгал бүрийг script.js-д бич. Дараагийн дасгал руу шилжихдээ өмнөхөө /* */-аар comment болго.
  4. Console-оо нээ: Cmd + Option + J. Алдаа гарвал улаан мөрийг унш.
<!doctype html>
<html lang="mn">
  <head>
    <meta charset="UTF-8" />
    <title>JS дасгал</title>
  </head>
  <body>
    <h1>JS дасгал</h1>

    <script src="script.js"></script>
  </body>
</html>

ДАСГАЛ 6Дунд

Хямдрал

Барааны үнэ, хямдралын хувийг асуугаад хэдэн төгрөг хямдарч, хэдийг төлөхийг Console-д бич.

ЖИШЭЭ

prompt

Барааны үнэ?

80000
→
prompt

Хэдэн хувийн хямдрал?

25
→
console› Хямдрал: 20000₮› Төлөх: 60000₮

💡 Хямдрал = үнэ × хувь / 100

Хэрэглэх: prompt · Number() · * · / · −

Хариулт — эхлээд өөрөө хий
const price = Number(prompt("Барааны үнэ?"));
const percent = Number(prompt("Хэдэн хувийн хямдрал?"));

const discount = price * percent / 100;
const finalPrice = price - discount;

console.log("Хямдрал: " + discount + "₮");
console.log("Төлөх: " + finalPrice + "₮");

ДАСГАЛ 9Хэцүү

Минутыг цаг болгох

Кино хэдэн минут үргэлжлэхийг асуугаад «2 цаг 15 минут» хэлбэрээр харуул.

ЖИШЭЭ

prompt

Хэдэн минут?

135
→
alert

2 цаг 15 минут

OK

💡 135 % 60 = 15 → үлдсэн минут. (135 − 15) / 60 = 2 → цаг.

Хэрэглэх: prompt · Number() · % · − · /

Хариулт — эхлээд өөрөө хий
const total = Number(prompt("Хэдэн минут?"));

const minutes = total % 60;
const hours = (total - minutes) / 60;

alert(hours + " цаг " + minutes + " минут");

🎮 Тоглогчийн профайл

Нэр, төрсөн он, дуртай тоглоомыг асуу. Насыг бодоод мэдээлэл бүрийг Console-д, бүгдийг нь нэг alert-д харуул.

ЖИШЭЭ

prompt

Тоглогчийн нэр?

Бат
→
prompt

Төрсөн он?

2008
→
prompt

Дуртай тоглоом?

Minecraft
→
console› Нэр: Бат› Нас: 18› Тоглоом: Minecraft
→
alert

🎮 Бат · 18 настай · Minecraft

OK

💡 Нас = 2026 − төрсөн он

Хэрэглэх: prompt · Number() · − · console.log · alert

Хариулт — эхлээд өөрөө хий
const playerName = prompt("Тоглогчийн нэр?");
const birthYear = Number(prompt("Төрсөн он?"));
const favoriteGame = prompt("Дуртай тоглоом?");

const age = 2026 - birthYear;

console.log("Нэр: " + playerName);
console.log("Нас: " + age);
console.log("Тоглоом: " + favoriteGame);

alert("🎮 " + playerName + " · " + age + " настай · " + favoriteGame);
